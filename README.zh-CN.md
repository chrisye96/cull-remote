# Cull Remote for Adobe Lightroom Classic

[English](README.md) | 简体中文

在 iPhone 或 iPad 上给电脑里 Lightroom Classic 的照片打旗标、星级和色标。所有写入都由 Lightroom 通过官方 SDK 完成，本工具从不直接打开 catalog 文件；手机上的每次标记在 Lightroom 里都是一条可以 `编辑 > 还原` 的记录。

## 组成

- `plugin/cull-remote.lrplugin`：Lightroom 增效工具，长轮询本机伴随服务并执行指令
- `server/`：电脑上运行的伴随服务（Node.js 24），只监听 `127.0.0.1`
- `web/`：手机和平板上打开的网页
- `spike/`：开发期的预览性能实验，结论见 `docs/spike-results.md`

## 一次性安装

1. `npm install`
2. Lightroom Classic：`文件 > 增效工具管理器 > 添加`，选择 `plugin/cull-remote.lrplugin`
3. Tailscale：电脑、iPhone、iPad 登录同一账号；在管理后台 `https://login.tailscale.com/admin/dns` 启用 MagicDNS 和 HTTPS Certificates
4. `tailscale serve --bg 47800`（只把网页端口暴露给自己的 tailnet，重启后保留）

## 日常使用

1. 打开 Lightroom Classic。在 Windows 上增效工具会自己在后台启动伴随服务（没有窗口），Lightroom 退出约一分钟后服务也会退出。前提是 `node` 在 PATH 里，并且增效工具留在本仓库目录内（它按自己的位置找到服务）。服务的输出写在 `.cache/server.log`
2. 配对设备时，在 Lightroom 里选 `图库 > 增效工具额外功能 > Cull Remote: show address and QR code`，浏览器会打开设置页，显示 tailnet 地址和二维码
3. 用 iPhone 或 iPad 扫码（设备上 Tailscale 需开启）。建议在 Safari 里"添加到主屏幕"，这样可以全屏使用

在 macOS 上，或者想用终端时，打开 Lightroom 后运行 `npm start`：终端会打印同样的地址和二维码，增效工具发现服务已经在运行就不会再启动一个。

在家和外出用的是同一个地址；在家时 Tailscale 会自动走局域网直连。

## 操作

- 左右滑动，或点照片左右两侧切换
- 上滑留用，下滑排除。拖动时照片跟手移动，并提示松手后的结果；提前松手则什么都不发生。手势不会取消已有旗标：对已有同样旗标的照片重复手势，只会跳到下一张
- 点照片中间（中央约一半宽度）隐藏或显示标记药丸和文件名标签，并有简短提示
- 留用、排除会自动跳到下一张；星级和色标不跳（设置里可以改成任何标记都跳，或都不跳）
- 再点一次已激活的旗标、星级、色标即取消
- 过滤开关同时显示"未标记"和"全部"及数量；切换时若当前照片仍在新列表中，会停留在这张
- 标记会自动从 Lightroom 刷新，在另一台设备上的改动或在 Lightroom 里的撤销几秒内就会显示
- 横屏时操作移到右侧细栏：留用在星级上方，排除在色标上方（设置里开启左手模式后在左侧）
- 首页的搜索框输入即过滤文件夹和收藏夹（右侧的 × 按钮清空）；文件夹可按名称或导入顺序排序，照片可选拍摄时间或文件名顺序。有子项的行可以展开和折叠。横屏时搜索和排序固定在左侧一列，列表在右侧滚动
- 首页最上方的"最近打开"列出本设备最近打开过的 5 个文件夹或收藏夹
- 接了键盘时，看片界面使用和 Lightroom 相同的按键：左右方向键切换，`P` 留用，`X` 排除，`U` 取消旗标，`1` 到 `5` 打星、`0` 清除星级，`6` 到 `9` 对应红、黄、绿、蓝色标
- 界面语言跟随设备：英语、简体中文、日语、德语、法语、西班牙语，设置里可以手动切换。旗标、星级、色标、文件夹、收藏夹这些词在每种语言里都和 Lightroom 的叫法一致
- 每个文件夹或收藏夹会记住上次看到的照片（按设备保存），返回后再进入会回到那一张

## 离线使用

- 首页"最近打开"里每一行末尾有 `缓存` 按钮。点开后选"缓存未标记"或"缓存全部"，按钮上写着张数和预估大小；缓存期间保持页面在前台，中断后再点一次会从断点继续。缓存完成后弹窗自动关闭，按钮变为 `已缓存 N`，文件夹列表里已缓存的文件夹在数量前有一个小勾。再点开时按钮会写出还差多少张，已经全部缓存的选项不可点。缓存到一半嫌慢，可以取消后在设置里调低清晰度再继续：已经下载的高清预览照常使用，只补下还没有的部分
- 想缓存还没打开过的文件夹，先进去一次，它就会出现在"最近打开"
- 手机和电脑在同一个局域网时，进入文件夹会自动缓存未标记的照片（默认最多 500 张，可在设置里关闭或调整）
- 连不上电脑时，缓存过的文件夹照常浏览和打标。顶部显示 `离线，待同步 N 条`，照片的标记药丸里有一个云朵图标；标记保存在设备上，关掉页面也不会丢
- 恢复连接后标记按原来的顺序自动同步到 Lightroom。Lightroom 没开时同样先存着，打开后自动补上
- 设置页（首页右上角）：预览清晰度、打标后是否跳到下一张、进入文件夹时显示未标记还是全部、左手模式、自动缓存、缓存占用与清除、连接信息。清除缓存只删预览图和照片列表，不会删掉还没同步的标记

删除照片不在本工具范围内：在手机上打"排除"，回到电脑后用 Lightroom 的 `照片 > 删除排除的照片`。

## 排查

- 网页顶部提示"Lightroom 未运行"：确认 Lightroom 已打开且增效工具状态为"已安装并正在运行"。仍不行时，点 `图库 > 增效工具额外信息 > Cull Remote: start bridge` 手动重启增效工具的连接
- 增效工具日志：`%TEMP%\cull-remote-plugin.log`，记录启动、退出和出错的命令
- 电脑本机访问 `https://<机器名>.ts.net` 可能超时，这是 Windows 没有使用 MagicDNS 解析，不影响手机和平板
- 在 Safari 里从屏幕左边缘右滑是浏览器的"后退"手势，会离开页面。从主屏幕图标打开可以避免

## 开发

- `npm test`
- 不碰日常使用的服务做测试：设置环境变量 `LRC_DEV=1` 后 `npm start` 会在 `47810/47811` 另起一个实例，再运行 `node spike/stand-in-plugin.mjs` 充当 Lightroom 增效工具（照片是假的，标记只存在内存里）
- 界面文字都在 `web/js/strings.js`，每种语言一张表，以英语为基准。新增语言时在那里加一张表，并把语言名加到 `web/js/i18n.js` 的 `LANGUAGES`；缺少键或占位符时 `npm test` 会失败。`tools/lightroom-terms.json` 列出了 Lightroom 在它支持的每种语言里对各个概念的叫法
- logo 和图标是生成出来的：`docs/brand/` 和 `web/icons/` 由脚本产生，说明见 `tools/README.md`
- 分支：`main` 稳定，`dev` 集成，功能在 `feat/*`，修复在 `fix/*`

## 已知限制

- 打开文件夹或收藏夹期间，标记自动从 Lightroom 刷新（每 5 秒，很大的文件夹会更久）；新增或移除的照片需要返回再进入才会显示
- 预览图缓存在 `.cache/previews/`，照片在 Lightroom 里重新调色后不会自动刷新，删除该目录即可
- "Lightroom 正忙"时标记会留在队列里稍后重试，这条路径只有自动化测试覆盖：实测中首选项、导出等对话框都不会阻止写入，无法人工复现
- 只识别 Lightroom 默认的五种色标；使用自定义色标集打的标签会显示为未标记，点按色块会替换掉原标签
- 离线数据保存在浏览器里，Safari、Chrome 和主屏幕应用各有一份，互不共享。只有从主屏幕图标打开，iOS 才不会在 7 天没有访问后清理这些数据
- 离线功能已在 iOS 的 Chrome 上逐项实测可用（iPhone 与 iPad，2026-10-04）。Safari 和主屏幕应用用的是同一个浏览器内核，预期同样可用，但还没有逐项实测
- Android 尚未测试：页面带有 web manifest 和图标，Chrome 可以把它安装到主屏幕，但还没有在任何 Android 设备上试过
- 日语、德语、法语、西班牙语是机器翻译的。和 Lightroom 共用的词取自 Lightroom 本身，其余句子还没有母语者看过，欢迎修正
- 完全没有网络时冷启动要等几秒（页面外壳和连接探测各有超时）
- 缓存到设备上的预览同样不会随 Lightroom 里的重新调色更新，需要在设置里清除缓存后重新缓存
