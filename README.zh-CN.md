# Cull Remote for Adobe Lightroom Classic

[English](README.md) | 简体中文

在 iPhone 或 iPad 上给电脑里 Lightroom Classic 的照片打旗标、星级和色标。

所有写入都由 Lightroom 通过官方 SDK 完成，本工具从不直接打开目录文件；手机上的每次标记在 Lightroom 里都是一条可以 `编辑 > 还原` 的记录。

## 需要准备什么

- 一台装有 Lightroom Classic 10 或更新版本的 Windows 或 macOS 电脑
- 电脑上装有 [Node.js](https://nodejs.org) 24 或更新版本
- 电脑和每台手机、平板上都装有 [Tailscale](https://tailscale.com)，并登录同一个账号

## 一次性安装

1. 获取文件：从[最新发布页](https://github.com/chrisye96/cull-remote/releases/latest)下载 **Source code (zip)**，解压到一个可以长期放置的位置；或者克隆本仓库。Lightroom 会直接从这个文件夹里运行增效工具
2. 在这个文件夹里运行 `npm install`
3. 在 Lightroom Classic 里选 `文件 > 增效工具管理器 > 添加`，选择 `plugin/cull-remote.lrplugin`
4. 在 Tailscale 管理后台的 [DNS 页面](https://login.tailscale.com/admin/dns)启用 MagicDNS 和 HTTPS Certificates
5. 运行 `tailscale serve --bg 47800`。它只暴露网页端口，只对你自己的 tailnet 开放，重启后保留

## 日常使用

1. 打开 Lightroom Classic。
   - 在 Windows 上，增效工具会自己在后台启动伴随服务，没有窗口；Lightroom 退出约一分钟后服务也会退出。前提是 `node` 在 PATH 里，并且增效工具留在本文件夹内，因为它按自己的位置找到服务。服务的输出写在 `.cache/server.log`
   - 在 macOS 上，或者想用终端时，打开 Lightroom 后运行 `npm start`。增效工具发现服务已经在运行就不会再启动一个
2. 配对设备时，在 Lightroom 里选 `图库 > 增效工具额外信息 > Cull Remote: show address and QR code`，浏览器会打开设置页，显示 tailnet 地址和二维码。`npm start` 也会在终端里打印同样的地址和二维码
3. 用 iPhone 或 iPad 扫码，设备上的 Tailscale 需要开启。建议在 Safari 里"添加到主屏幕"，这样可以全屏使用

在家和外出用的是同一个地址；在家时 Tailscale 会自动走局域网直连。

## 操作

### 看片界面

| 操作 | 效果 |
|---|---|
| 左右滑动，或点照片左右两侧 | 切换照片 |
| 上滑 | 留用 |
| 下滑 | 排除 |
| 点旗标、星星或颜色 | 打上标记；再点一次已激活的即取消 |
| 点照片中间（中央约一半宽度） | 隐藏或显示照片上的全部信息：标记药丸、文件名标签和照片信息 |
| 点照片信息面板 | 收成一个图标；点图标再展开 |
| 点"返回"旁边的网格按钮 | 打开缩略图网格。此时按钮变成单张照片的图标，再点一次回到照片 |
| 点"未标记"或"全部" | 切换过滤，两者都显示实时数量 |
| 点网格按钮旁边的漏斗 | 筛选：未标记、未排除或全部，或按一种标记：留用、排除、正好几星、几星及以上，或某一种色标 |

- 点按区域跟着照片走：点窄照片两旁的空白，或照片本身靠边的部分，都是翻页；照片中央约一半宽度才是隐藏或显示信息
- 上下拖动时照片跟手移动，并提示松手后的结果；提前松手则什么都不发生
- 手势不会取消已有旗标：对已有同样旗标的照片重复手势，只会跳到下一张
- 留用、排除会自动跳到下一张；星级和色标不跳。设置里可以改成任何标记都跳，或都不跳
- 切换过滤时，若当前照片仍在新列表中，会停留在这张
- 按标记筛选一次只选一种，适合第二遍、第三遍筛片。"未排除"显示除了被排除之外的所有照片，第二遍筛选时仍能看到第一遍打过星的照片。菜单最上面是"未标记""未排除""全部"，下面列出每种标记以及各自会显示多少张：两种旗标、两列星级（"★3"是正好三星，"★3+"是三星及以上）和五种色标。筛选生效时漏斗会变成对应的标记；在菜单里再点一次这一项，或点"未标记"或"全部"即退出
- 标记会自动从 Lightroom 刷新，在另一台设备上的改动或在 Lightroom 里的还原几秒内就会显示
- 横屏时操作移到右侧细栏：留用在星级上方，排除在色标上方。设置里开启左手模式后细栏在左侧
- 每个文件夹或收藏夹会记住上次看到的照片（按设备保存），返回后再进入会回到那一张
- 照片信息面板依次显示预览图的直方图，快门、光圈和 ISO，焦距和镜头。它浮在照片区域的右上角；平板横屏时改放在细栏里，不遮挡照片。设置里可以选择三部分各自是否显示

### 缩略图网格

网格用来总览一个文件夹，以及跳到某一张照片。它只用来看，打标仍在单张照片上进行。

- 列出的照片和看片界面相同，同样受"未标记"或"全部"过滤
- 每张缩略图带有照片的标记：旗子或排除符号，一颗星加数字，色标是底边的一条色带。排除的照片会变暗
- 点一张缩略图就打开那张照片。再回到网格时，刚才那张有边框标出，并且已经滚到可见位置
- 再点网格按钮回到单张照片
- 缩略图滚到可见位置时才加载。Lightroom 还没有预览的文件夹里，每张要等几秒，到达之前先显示文件名

### 使用键盘

看片界面使用和 Lightroom 相同的按键。

| 按键 | 效果 |
|---|---|
| 左右方向键 | 上一张、下一张 |
| `P` | 留用 |
| `X` | 排除 |
| `U` | 取消旗标 |
| `1` 到 `5` | 打星 |
| `0` | 清除星级 |
| `6` 到 `9` | 红、黄、绿、蓝色标 |
| `G` | 打开或关闭缩略图网格 |
| `Esc` | 退出网格 |

网格打开时，打标的按键不起作用。

### 首页

- 在搜索框输入即过滤文件夹和收藏夹，右侧的 × 按钮清空
- 文件夹可按名称或导入顺序排序，照片可选拍摄时间或文件名顺序
- 有子项的行可以展开和折叠
- 最上方的"最近打开"列出本设备最近打开过的 5 个文件夹或收藏夹
- 横屏时搜索和排序固定在左侧一列，列表在右侧滚动

### 设置

设置在首页右上角：语言、预览清晰度、打标后是否跳到下一张、进入文件夹时显示未标记还是全部、左手模式、照片信息显示哪几部分、自动缓存、缓存占用与清除、连接信息。

## 语言

界面语言跟随设备：英语、简体中文、日语、德语、法语、西班牙语，设置里可以手动切换。

旗标、星级、色标、文件夹、收藏夹这些词在每种语言里都和 Lightroom 的叫法一致。

## 离线使用

**缓存一个文件夹**

- 首页每个文件夹和收藏夹的行尾（包括"最近打开"里的）有一个小箭头，点它打开缓存弹窗。点开后选"缓存未标记"或"缓存全部"，按钮上写着张数和预估大小
- 只想带走某一种标记的照片（比如出门做第二遍筛选），在弹窗里展开"按标记选择"，点一种标记（和看图界面的筛选菜单是同一块面板），下面会多出第三个按钮，写着这种标记的张数和大小
- 缓存期间保持页面在前台，中断后再点一次会从断点继续
- 缓存完成后弹窗自动关闭，这个文件夹的小箭头变成小勾
- 再点开时按钮会写出还差多少张，已经全部缓存的选项不可点
- 想腾出某个文件夹占的空间，在它的弹窗里点"删除已缓存的预览图"，再点一次确认；第二次点之前按钮上会写出张数和大小。同一张照片如果也在别的文件夹或收藏夹里，那边的预览图也会一起消失。全部清空用设置里的"清除缓存"
- 缓存到一半嫌慢，可以取消后在设置里调低清晰度再继续：已经下载的高清预览照常使用，只补下还没有的部分

**自动缓存**

手机和电脑在同一个局域网时，进入文件夹会自动缓存未标记的照片，默认最多 500 张，可在设置里关闭或调整。

**连不上电脑时**

- 缓存过的文件夹照常浏览和打标
- 顶部显示 `离线，待同步 N 条`，照片的标记药丸里有一个云朵图标
- 标记保存在设备上，关掉页面也不会丢
- 恢复连接后标记按原来的顺序自动同步到 Lightroom。Lightroom 没开时同样先存着，打开后自动补上

在设置里清除缓存只删预览图和照片列表，不会删掉还没同步的标记。

## 删除照片

删除照片特意不在本工具范围内：在手机上打"排除"，回到电脑后用 Lightroom 的 `照片 > 删除排除的照片`。

## 排查

- **网页顶部提示"Lightroom 未运行"。** 确认 Lightroom 已打开且增效工具状态为"已安装并正在运行"。仍不行时，点 `图库 > 增效工具额外信息 > Cull Remote: start bridge` 手动重启增效工具的连接
- **增效工具日志。** `%TEMP%\cull-remote-plugin.log` 记录启动、退出和出错的命令
- **在电脑本机打开地址超时。** 访问 `https://<机器名>.ts.net` 可能超时，这是 Windows 没有使用 MagicDNS 解析，不影响手机和平板
- **在 Safari 里滑动时离开了页面。** 从屏幕左边缘右滑是浏览器的"后退"手势。从主屏幕图标打开可以避免

## 组成

| 目录 | 内容 |
|---|---|
| `plugin/cull-remote.lrplugin` | Lightroom 增效工具，长轮询本机伴随服务并执行指令 |
| `server/` | 电脑上运行的伴随服务（Node.js 24），只监听 `127.0.0.1` |
| `web/` | 手机和平板上打开的网页 |
| `tools/` | 生成 logo 文件、页面里的图标和 Lightroom 术语表的脚本，见 `tools/README.md` |
| `spike/` | 开发期的预览性能实验，结论见 `docs/spike-results.md` |

网页通过 `tailscale serve` 以 HTTPS 发布给你自己的设备，只在你的 tailnet 内可达，不会暴露到公网。

## 开发

- 用 `npm test` 运行测试
- 不碰日常使用的服务做测试：设置环境变量 `LRC_DEV=1` 后，`npm start` 会在 `47810` 和 `47811` 端口另起一个实例，再运行 `node spike/stand-in-plugin.mjs` 充当 Lightroom 增效工具（照片是假的，标记只存在内存里）
- 界面文字都在 `web/js/strings.js`，每种语言一张表，以英语为基准。新增语言时在那里加一张表，并把语言名加到 `web/js/i18n.js` 的 `LANGUAGES`。缺少键或占位符时 `npm test` 会失败
- `tools/lightroom-terms.json` 列出了 Lightroom 在它支持的每种语言里对各个概念的叫法
- logo 和图标是生成出来的：`docs/brand/` 和 `web/icons/` 由脚本产生，说明见 `tools/README.md`
- 界面上的图标取自 Lucide，只把用到的那些复制进 `web/index.html`。新增或去掉图标后，在仓库根目录运行 `node tools/icons.mjs`；页面和实际用到的图标不一致时 `npm test` 会失败
- 分支：`main` 稳定，`dev` 集成，功能在 `feat/*`，修复在 `fix/*`

## 已知限制

**标记和预览**

- 打开文件夹或收藏夹期间，标记自动从 Lightroom 刷新，每 5 秒一次，很大的文件夹会更久。新增或移除的照片需要返回再进入才会显示
- 电脑上的预览图缓存在 `.cache/previews/`，照片在 Lightroom 里重新调色后不会自动刷新，删除该目录即可
- 缓存到设备上的预览同样不会随 Lightroom 里的重新调色更新，需要在设置里清除缓存后重新缓存
- 只识别 Lightroom 默认的五种色标。使用自定义色标集打的标签会显示为未标记，点按色块会替换掉原标签
- "Lightroom 正忙"时标记会留在队列里稍后重试，这条路径只有自动化测试覆盖：实测中首选项、导出等对话框都不会阻止写入，无法人工复现
- 直方图是从屏幕上的预览图统计的，不是从 RAW 文件，而且用的是缩小后的副本，所以极少量的过曝或死黑像素可能看不出来
- 旧版本缓存过的文件夹，要在有连接时打开一次，才会显示曝光和镜头信息
- 网格的缩略图 Lightroom 给的比要的大，每张约 60 KB，用流量时积少成多

**离线**

- 离线数据保存在浏览器里，Safari、Chrome 和主屏幕应用各有一份，互不共享。只有从主屏幕图标打开，iOS 才不会在 7 天没有访问后清理这些数据
- 离线功能已在 iOS 的 Chrome 上逐项实测可用（iPhone 与 iPad，2026-10-04）。Safari 和主屏幕应用用的是同一个浏览器内核，预期同样可用，但还没有逐项实测
- 完全没有网络时冷启动要等几秒，因为页面外壳和连接探测各有超时
- 缩略图本身不缓存。离线时网格按设计会改用已缓存的预览图，这一点还没有在设备上实测

**平台和语言**

- Android 尚未测试：页面带有 web manifest 和图标，Chrome 可以把它安装到主屏幕，但还没有在任何 Android 设备上试过
- 日语、德语、法语、西班牙语是机器翻译的。和 Lightroom 共用的词取自 Lightroom 本身，其余句子还没有母语者看过，欢迎修正
