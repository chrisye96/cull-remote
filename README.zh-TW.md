# Cull Remote for Adobe Lightroom Classic

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文**

在 iPhone 或 iPad 上挑選 Lightroom Classic 的相片：為電腦上的編目設定留用與排除旗標、星級評等和顏色標籤。

所有寫入都透過 Lightroom 的官方 SDK 完成。本工具從不直接開啟編目檔案，手機上的每個標記在 Lightroom 裡都是一個普通步驟，可以用「編輯 > 還原」（`Edit > Undo`）還原。

## 需要準備什麼

- 一台裝有 Lightroom Classic 10 或更新版本的 Windows 或 macOS 電腦
- 這台電腦上裝有 [Node.js](https://nodejs.org) 24 或更新版本
- 電腦和每台手機或平板上都裝有 [Tailscale](https://tailscale.com)，並登入同一個帳號

## 一次性設定

1. 取得檔案：從[最新發行版](https://github.com/chrisye96/cull-remote/releases/latest)下載 **Source code (zip)**，解壓縮到可以長期存放的位置；或 clone 這個儲存庫。Lightroom 會直接從這個資料夾裡執行增效模組
2. 在這個資料夾裡執行 `npm install`
3. 在 Lightroom Classic 中選擇「檔案 > 增效模組管理員 > 增加」（`File > Plug-in Manager > Add`），然後選取 `plugin/cull-remote.lrplugin`
4. 在 Tailscale 管理主控台的 [DNS 頁面](https://login.tailscale.com/admin/dns)啟用 MagicDNS 和 HTTPS Certificates
5. 執行 `tailscale serve --bg 47800`。它只公開網頁連接埠，只對你的 tailnet 開放，重新開機後依然有效

## 日常使用

1. 開啟 Lightroom Classic。
   - 在 Windows 上，增效模組會自行在背景啟動伴隨伺服器，不會出現視窗。Lightroom 結束約一分鐘後，伺服器也會結束。前提是 `node` 在 PATH 中，且增效模組留在這個資料夾內，因為它是在自己旁邊找到伺服器的。伺服器的輸出寫在 `.cache/server.log`
   - 在 macOS 上，或你偏好使用終端機時，開啟 Lightroom 後執行 `npm start`。增效模組會使用已在執行的伺服器，不會再啟動一個
2. 要配對裝置，請在 Lightroom 中選擇「圖庫 > 增效模組額外資訊 > Cull Remote: show address and QR code」（`Library > Plug-in Extras > Cull Remote: show address and QR code`）。瀏覽器會開啟設定頁面，顯示 tailnet 位址和 QR Code。`npm start` 也會在終端機裡印出同樣的位址和 QR Code
3. 開啟 Tailscale，用 iPhone 或 iPad 掃描 QR Code。在 Safari 中使用「加入主畫面」，就能以全螢幕應用程式的方式使用

在家和外出都用同一個位址。在家時，Tailscale 會透過區域網路直接連線。

## 操作方式

### 在檢視畫面中

| 操作 | 效果 |
|---|---|
| 向左或向右滑動，或點相片的左側或右側 | 切換相片 |
| 向上滑 | 留用 |
| 向下滑 | 排除 |
| 點旗標、星星或顏色 | 設定該標記；再點一次已啟用的標記即可清除 |
| 點相片中間（中央一半的範圍） | 隱藏或顯示覆蓋在相片上的所有資訊：標記膠囊、檔名標籤和相片資訊 |
| 點相片資訊面板 | 收合成一個圖示；點圖示即可再次展開 |
| 點「返回」旁邊的網格按鈕 | 開啟縮圖網格。按鈕隨即變成單張相片的圖示；再點一次即可返回 |
| 點「未標記」或「全部」 | 切換篩選；兩者都會即時顯示數量 |
| 點網格按鈕旁邊的漏斗 | 選擇篩選條件：未標記、未排除或全部，或單一種標記：留用、排除、某個評等、最低評等，或某個顏色標籤 |

- 點按區域跟著相片走。在窄相片的兩旁，或相片本身靠外側的部分點一下會翻頁；點相片本身中央的一半，才會隱藏或顯示覆蓋資訊
- 上下拖曳時，相片會跟著手指移動，並以提示顯示放開後的結果。提早放開則什麼都不會發生
- 手勢不會清除旗標：對已有該旗標的相片重複同一手勢，只會跳到下一張
- 留用和排除會跳到下一張相片；星級和標籤則停留在目前這張。設定中可以改成每種標記都跳到下一張，或都不跳
- 切換篩選時，如果目前的相片也在新的清單中，就會停留在這張
- 標記篩選一次只顯示一種相片，適合第二輪或第三輪挑片。「未排除」會顯示排除以外的所有相片，所以後面一輪仍看得到前一輪評過的星級。選單最上方是「未標記」、「未排除」和「全部」，接著列出每種標記，以及各自會顯示的相片數量：兩種旗標、每列兩個的評等（「★3」是正好三星，「★3+」是三星以上）和五種顏色。啟用其中一種時，漏斗會變成該標記；在選單中再點一次它，或點「未標記」或「全部」即可離開
- 標記會自動從 Lightroom 重新整理，因此在另一台裝置上做的變更，或在 Lightroom 中還原的操作，幾秒內就會出現
- 橫向時，控制項會移到右側的窄欄：留用在星級上方，排除在顏色標籤上方。在設定中開啟左手模式，窄欄就會改到左側
- 每個檔案夾或集合都會記住你看到哪張相片（每台裝置各自記錄），返回後再開啟就會從那張繼續
- 相片資訊面板依序顯示預視的色階分佈圖，接著是快門速度、光圈和 ISO，然後是焦距和鏡頭。它覆蓋在相片區域的右上角；在橫向的平板上則改放在窄欄中，不會遮住任何東西。設定中可以選擇三個部分各自是否顯示

### 縮圖網格

網格用來總覽一個檔案夾，並快速跳到某張相片。它只負責顯示：標記仍在單張相片上進行。

- 它列出的相片與檢視畫面相同，並跟隨檢視畫面的篩選
- 每張縮圖都帶有相片的標記：旗標或排除符號、一顆星加上數字，以及沿著底邊的一條顏色標籤色帶。被排除的相片會變暗
- 點縮圖即可開啟那張相片。回到網格時，你剛才看的相片會加上外框，並捲動到可見位置
- 網格按鈕會帶你回到單張相片
- 縮圖會在捲動到可見範圍時載入。在 Lightroom 尚未產生預視的檔案夾中，每張要等幾秒，載入前會先顯示檔名

### 使用鍵盤

檢視畫面使用與 Lightroom 相同的按鍵。

| 按鍵 | 功能 |
|---|---|
| 左右方向鍵 | 上一張和下一張相片 |
| `P` | 留用 |
| `X` | 排除 |
| `U` | 移除旗標 |
| `1` 到 `5` | 設定星級評等 |
| `0` | 清除評等 |
| `6` 到 `9` | 紅色、黃色、綠色和藍色標籤 |
| `G` | 開啟或關閉縮圖網格 |
| `Esc` | 離開網格，或關閉篩選選單 |

網格開啟時，用來標記的按鍵不起作用。

### 在首頁

- 搜尋會在輸入時即時篩選檔案夾和集合；× 按鈕可清除搜尋
- 檔案夾可依名稱或讀入順序排序，相片順序可選擇拍攝時間或檔名
- 有子項目的列可以展開和收合
- 最上方的「最近打開」列出這台裝置上最近開啟過的五個檔案夾或集合
- 橫向時，搜尋和排序控制項固定在左側一欄，清單則在右側捲動

### 設定

設定位於首頁右上角：語言、預視品質、標記後是否跳到下一張相片、開啟檔案夾時顯示未標記還是全部相片、左手模式、要顯示哪些相片資訊、自動快取、快取用量與清除，以及連線資訊。

## 語言

介面語言跟隨裝置：英文、簡體中文、日文、德文、法文或西班牙文。設定中有切換選項。

旗標、評等、標籤、檔案夾和集合的名稱，在每種語言中都與 Lightroom 的叫法一致。

## 離線使用

**快取檔案夾**

- 首頁上每個檔案夾和集合的末端（包括「最近打開」中的）都有一個小箭頭。點它會開啟對話框，讓你選擇快取未標記的相片或全部相片；按鈕上會顯示相片數量和預估大小
- 若只想帶走某一種標記的相片，以便外出時做第二輪挑片，可在該對話框中展開「按標記選擇」，再點一種標記（與檢視畫面的篩選選單是同一個面板）。這時會出現第三個按鈕，顯示該標記的相片數量和大小
- 快取期間請讓頁面保持在前景。如果中斷了，再點一次就會從中斷處繼續
- 完成後對話框會關閉，該檔案夾的箭頭會變成勾號
- 再次開啟對話框時，會顯示還缺多少張相片，已完整快取的選項會停用
- 要釋放某個檔案夾占用的空間，請在它的對話框中點「刪除已緩存的預覽圖」，再點一次確認；第二次點按時會標出相片數量和大小。同一張相片如果也在其他檔案夾或集合中，那裡的預視也會一併消失。設定中的「清除緩存」會移除所有快取
- 如果快取太慢，可以取消，在設定中調低預視品質後再繼續。已下載的高品質預視會繼續使用，只會補抓缺少的部分

**自動快取**

手機和電腦在同一個區域網路時，開啟檔案夾會自動快取其中未標記的相片，預設最多 500 張。可以在設定中關閉此功能或調整上限。

**連不上電腦時**

- 已快取的檔案夾仍可照常瀏覽和標記
- 頂端列會顯示 `Offline, N waiting to sync`（中文介面為「離線，待同步 N 條」），標記膠囊會顯示雲朵圖示
- 標記儲存在裝置上，關閉頁面也不會遺失
- 恢復連線後，標記會依你操作的順序同步到 Lightroom。Lightroom 關閉時也一樣：標記會先等待，Lightroom 開啟後再送達

在設定中清除快取只會移除預視和相片清單，絕不會移除尚未同步的標記。

## 刪除相片

本工具刻意不提供刪除功能。請在手機上將相片標記為排除，再到電腦上使用 Lightroom 的「相片 > 刪除排除的相片」（`Photo > Delete Rejected Photos`）。

## 疑難排解

- **網頁顯示 Lightroom 沒有在執行。** 請確認 Lightroom 已開啟，且增效模組的狀態為「已安裝且正在執行」（Installed and running）。如果仍然失敗，請用「圖庫 > 增效模組額外資訊 > Cull Remote: start bridge」（`Library > Plug-in Extras > Cull Remote: start bridge`）重新啟動增效模組的連線
- **增效模組記錄檔。** `%TEMP%\cull-remote-plugin.log` 會記錄啟動、結束和執行失敗的指令
- **在電腦本機上開啟位址會逾時。** 在電腦上開啟 `https://<machine>.ts.net` 時，如果 Windows 不解析 MagicDNS 名稱，就可能逾時。手機和平板不受影響
- **在 Safari 中滑動時離開了頁面。** 從螢幕左邊緣滑動是瀏覽器的返回手勢。從主畫面圖示開啟應用程式即可避免

## 運作架構

| 資料夾 | 內容 |
|---|---|
| `plugin/cull-remote.lrplugin` | Lightroom 增效模組，對本機的伴隨伺服器進行長輪詢，並執行它的指令 |
| `server/` | 在你電腦上執行的伴隨伺服器（Node.js 24），只監聽 `127.0.0.1` |
| `web/` | 在手機或平板上開啟的網頁 |
| `tools/` | 產生 logo 檔案、頁面中的圖示 sprite 和 Lightroom 術語表的指令碼；請參閱 `tools/README.md` |
| `spike/` | 開發期間的預視效能實驗；結果在 `docs/spike-results.md` |

網頁透過 `tailscale serve` 以 HTTPS 發布到你自己的裝置上。只有在你的 tailnet 內才連得到，絕不會出現在公開網際網路上。

## 開發

- 使用 `npm test` 執行測試
- 若要在不影響日常使用中的伺服器的情況下測試，請設定環境變數 `LRC_DEV=1`：此時 `npm start` 會在連接埠 `47810` 和 `47811` 執行第二個執行個體，而 `node spike/stand-in-plugin.mjs` 會扮演 Lightroom 增效模組，使用保存在記憶體中的假相片和假標記
- 所有介面文字都在 `web/js/strings.js`，每種語言一張表，以英文為基準。要新增語言，請在那裡加一張表，並把語言名稱加到 `web/js/i18n.js` 的 `LANGUAGES`。缺少鍵或預留位置時，`npm test` 會失敗
- `tools/lightroom-terms.json` 列出 Lightroom 在它所有語言中對每個項目的叫法
- Logo 和圖示是產生出來的：`docs/brand/` 和 `web/icons/` 來自 `tools/README.md` 中說明的指令碼
- 介面圖示是複製進 `web/index.html` 的 Lucide 圖示，只包含用到的那些。新增或移除圖示後，請在儲存庫根目錄執行 `node tools/icons.mjs`；在頁面與之一致之前，`npm test` 都會失敗
- 分支：`main` 是穩定版，`dev` 用於整合，功能放在 `feat/*`，修正放在 `fix/*`

## 已知限制

**標記與預視**

- 開啟檔案夾或集合期間，標記會從 Lightroom 重新整理，每 5 秒一次，非常大的檔案夾則間隔更長。加入或移除的相片要返回後再開啟才會出現
- 預視快取在電腦上的 `.cache/previews/` 中，在 Lightroom 裡重新編輯相片後不會更新。刪除該資料夾即可重新整理
- 快取在裝置上的預視也不會跟著 Lightroom 中後續的編輯更新。請在設定中清除快取後重新快取
- 只能辨識 Lightroom 預設的五種顏色標籤。透過自訂標籤組合標上的相片會顯示為未標記，點選顏色會取代原本的標籤
- Lightroom 忙碌時，標記會留在佇列中並重試。這條路徑只有自動化測試涵蓋：實際上，偏好設定和轉存等對話框都不會阻擋寫入，因此無法手動重現
- 色階分佈圖是根據螢幕上的預視計算的，而不是 RAW 檔，而且用的是縮小後的副本，因此少量被剪裁的像素可能看不出來
- 由舊版快取以供離線使用的檔案夾，在連線狀態下開啟一次之前，不會顯示曝光或鏡頭資訊
- Lightroom 提供的網格縮圖比要求的大，每張約 60 KB，使用行動數據時會累積不少

**離線**

- 離線資料存在瀏覽器裡：Safari、Chrome 和主畫面應用程式各自保有一份。只有主畫面應用程式不會被 iOS 在 7 天未造訪後清除這些資料
- 離線使用已在 iOS 上的 Chrome 逐項驗證（iPhone 和 iPad，2026-10-04）。Safari 和主畫面應用程式使用相同的瀏覽器引擎，預期行為相同，但尚未逐項驗證
- 完全沒有網路時，冷啟動需要幾秒，因為頁面外殼和連線探測都要等到逾時
- 縮圖本身不會快取。離線時，網格預計會改用已快取的預視；這一點尚未在裝置上驗證

**平台與語言**

- Android 尚未測試：頁面附有 web manifest 和圖示，讓 Chrome 可以把它安裝到主畫面，但還沒有在任何 Android 裝置上試過
- 日文、德文、法文和西班牙文是機器翻譯的。與 Lightroom 共用的詞取自 Lightroom 本身；其餘句子尚未經母語人士審閱，歡迎指正
